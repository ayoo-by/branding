## Not synced

- Components are static renditions of the ayoo.by theme's Hugo templates and CSS classes: there is no component library to bundle. The blog has no posts yet, so post titles, summaries and tags in the previews are examples; the markup is the templates'.
- `favicon.ico` stays in the branding repository's `favicons/` folder: this store does not take `.ico` files.
- This system is generated from ayoo-by/branding and the ayoo.by theme. Change those sources, rebuild with `bun run design-system`, and republish; edits made on this page would be overwritten.
