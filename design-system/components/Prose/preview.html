Keeping it small

Most of what I run is meant to sit in a corner for years. A few rules keep it there:

  • Small enough to read in an afternoon.
  • Patched upstream where it can be, carried locally where it cannot.
  • Quiet: no pager, no dashboard to babysit.
Software that stays small and runs for years.

For zestginx that means staying close to upstream NGINX. Every change gets a dry run with nginx -t, and HTTP/3 takes three lines of config:

listen 443 quic reuseport;
listen 443 ssl;
add_header Alt-Svc 'h3=":443"; ma=86400';

The second link shows the hover underline (sage-600); the first is at rest (sage-300).
