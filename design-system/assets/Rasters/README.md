# Rasters

Raster exports of `eagle-light.svg` and `eagle-dark.svg` at 32, 64, 180, 256, 512 and 1024px, from favicon to hero size. Each keeps its square background: beige `#f3f0e7` for light, navy `#0f1622` for dark.

- Use the SVGs wherever a vector works; these are for places that need a bitmap (social cards, app stores, documents).
- Pick the file at or above the display size; never upscale the 32px or 64px exports.
- At 32px and below the feather and tail lines blur; the heads and shield silhouette still hold.
- The PNGs are regenerable from the SVGs, which stay the source of truth.
